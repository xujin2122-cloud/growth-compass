连接 Google Drive 同步
配置一次，之后数据自动同步到你的 Google Drive，平板和电脑都能访问同一份数据。
1
打开 Google Cloud Console，用你的 Google 账号登录，新建一个项目（名字随意）
2
左侧菜单 → API 和服务 → 库，搜索 Google Drive API 并启用
3
左侧 → 凭据 → 点击「创建凭据」→ 选 OAuth 客户端 ID → 应用类型选「Web 应用」
在「已获授权的 JavaScript 来源」填入你打开此文件的网址（如果是本地文件请先将此 HTML 上传到 GitHub Pages）
4
创建后复制「客户端 ID」，粘贴到下方
⚠️ Google OAuth 在本地 file:// 协议下无法工作，需要通过 HTTP/HTTPS 访问。最简单的免费方案：将此 HTML 上传到 GitHub Pages，获得一个 https:// 网址。
